# 安装与验证

## 风险准备

安装前应具备：

- 已解锁且能够恢复的 Android 测试设备；
- 可用的 boot 镜像备份或官方恢复包；
- KernelSU、APatch，或能够加载对应 LKM 的 root 环境；
- 与当前内核和 KernelPatch ABI 匹配的构建产物。

内核模块错误可能导致重启、启动失败或数据丢失。不要先在唯一的日用设备上测试。

## 安装

1. 在 Release 页面下载模块 ZIP 和对应的 SHA-256 文件。
2. 在本地验证校验值。
3. 通过受支持的 root 管理器安装 ZIP。
4. 重启设备。
5. 从模块管理器打开 HIDHide WebUI。

原生支持 KPM 的环境会优先使用 `ksud kpm`。其他环境可以通过独立安装的
KernelPatch 兼容引擎加载 KPM。若包内只有传统 `.ko`，其内核版本必须精确匹配。

## 配置

- VID/PID 均留空：自动识别所有外接 USB 多点触摸设备。
- VID/PID 均填写：只处理指定设备。
- `name` 和 `phys`：设置呈现给 Android 输入层的名称和物理路径。

应用配置后重新插拔目标设备，使其重新执行输入设备注册流程。

## 验证

在 WebUI 中刷新设备列表，或者生成诊断报告。成功时应满足：

- 目标输入设备的总线显示为 I²C；
- VID/PID 和版本字段已清零；
- Android 将其判断为非外接输入设备；
- 触摸事件本身仍能正常产生。

诊断报告包含设备型号、内核版本、输入设备列表和相关内核日志。公开分享之前请先审阅，
必要时继续脱敏。

## 卸载

先断开目标外接触摸设备，再从 root 管理器禁用或卸载模块并重启。模块为已注册设备使用
独立的持久字符串副本，因此移除钩子不会留下指向模块静态内存的悬空指针；这些小块内存
会在设备重启时统一回收。
